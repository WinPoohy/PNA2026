В ходе работы базовая логика калькулятора была расширена продвинутыми UX/UI-решениями и математическими проверками, закрывающими требования по самостоятельной проработке:

| Функционал / Задача | Описание технической реализации |
|---|---------------------|
| **Управление DOM-деревом** | Настроена динамическая связь между кнопками сетки `.buttons-grid` и главным экраном вывода `#result`. |

| **Интеграция с ЭУ МГТУ** | Скрипт в реальном времени рассчитывает номер текущей учебной недели относительно 1 сентября и автоматически выводит её тип («Чис» / «Знам») в шапку профиля Бауманского портала. |

## 📁 Архитектура кодовой базы

Интерактивная часть распределена по следующим файлам:
* `script.js` — Ядро вычислительной логики. Содержит обработчики событий кликов, конечный автомат для хранения операндов `a`, `b` и знака операции, а также функции кастомизации интерфейса.
* `calc.html`, `index.html`, `about.html` — HTML-страницы, к которым подключен скрипт через `<script type="text/javascript" src="script.js"></script>`.
* `style.css` — Стили оформления, поддерживающие динамические изменения, инициированные JS.

## 💻 Разбор ключевых фрагментов скрипта

### 1. Защита интерфейса от переполнения и красивый вывод
Функция `updateDisplay` отвечает за сборку математического выражения, замену операторов и динамическое масштабирование текста:

```javascript
// Контроль корректного отображения больших данных
function formatPart(val) {
    if (val === '' || val === '-') return val;
    let num = Number(val);
    let str = val.toString();

    // Если число длиннее 9 знаков — переводим в экспоненциальный вид
    if (str.replace('-', '').replace('.', '').length > 9 || Math.abs(num) >= 1000000000) {
        return num.toExponential(4);
    }
    return str;
}

// Корректировка размера шрифта при вводе длинных цепочек
if (fullExpression.length > 14) {
    outputElement.style.fontSize = "20px";
} else {
    outputElement.style.fontSize = "40px";
}
```
