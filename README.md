## 🎯 Цель работы
Изучение принципов построения серверных приложений (Бэкенда) на платформе Node.js с использованием минималистичного фреймворка Express.js. Практическое освоение архитектурного стиля REST API, маршрутизации HTTP-запросов (`GET`, `POST`, `PUT`, `DELETE`), работы с промежуточным программным обеспечением (Middleware) и интеграции инженерной бизнес-логики в серверные эндпоинты.

---

## 🛠️ Выполненные задачи & Архитектурные решения

В рамках работы серверная часть была спроектирована как изолированный микросервис, готовый к интеграции с фронтендом из предыдущих ЛР:

| Компонент / Механизм | Описание технической реализации |
|---|---------------------|
| **Сервер на Express.js** | Создана базовая точка входа `src/index.js`, настроен запуск HTTP-сервера на порту `3000` с поддержкой автоматического перезапуска через `nodemon`. |
| **REST API для Stock** | Реализован полный CRUD-цикл обработки данных для сущности "Карточка товара/услуги" (`Stock`), имитирующий работу с базой данных через оперативную память (In-Memory DB). |
| **Инженерный API-модуль** | Логика CLI-скрипта `dz.js` успешно перенесена на сервер. Созданы эндпоинты для удаленной проверки префиксов проектов и RLE-сжатия серийных кодов. |
| **Middleware-цепочки** | Интегрирован встроенный парсер `express.json()` для автоматической обработки JSON-тел запросов. Реализована централизованная middleware-обработка ошибок 404 (Not Found). |
| **Тестирование в Postman** | Сформирована и успешно протестирована коллекция HTTP-запросов, валидирующая корректность ответов сервера и статус-кодов (`200 OK`, `201 Created`, `404 Not Found`). |
