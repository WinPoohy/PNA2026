## 📁 Структура проекта

Проект разделен на логические модули и представляет собой многостраничное веб-приложение:

* `index.html` — Главная страница, имитирующая личный кабинет Электронного Университета (плитка сервисов, лента новостей, контакты техподдержки).
* `calc.html` — Страница со встроенным кастомизированным калькулятором.
* `about.html` — Страница с информацией об авторе работы и ссылкой на GitHub.
* `style.css` — Единая таблица стилей, использующая CSS Variables и сеточные макеты (CSS Grid).
* `script.js` — Логика калькулятора и дополнительные скрипты автоматизации интерфейса.

## 💻 Ключевые фрагменты реализации

### 1. Архитектура стилей (CSS-переменные и сетки)
Для управления дизайном использованы CSS-переменные, что упрощает масштабирование проекта, а кнопки калькулятора выстроены по сетке `Grid (4x5)`:

```css
:root {
    --bmstu-blue: #0662bd;      /* Глубокий синий МГТУ */
    --accent-blue: #007bff;     /* Яркий синий для акцентов */
    --bg-light: #f4f7f9;
    --shadow-soft: 0 4px 15px rgba(0, 0, 0, 0.1);
}

/* Сетка кнопок калькулятора */
.buttons-grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 15px;
}

/* Кнопка телефона/равно на 2 колонки */
.my-btn.execute {
    grid-column: span 2;
    width: 100%;
    border-radius: 35px;
}
