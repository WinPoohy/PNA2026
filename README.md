## 2. Ход работы

### Часть 1. Переход на Fetch и Async/Await

В ходе работы сетевой слой был полностью переработан. Мы отказались от архитектуры коллбэков (из ЛР №5) в пользу цепочек промисов. Это позволило значительно упростить чтение кода и обработку потенциальных ошибок.

**Пример реализации асинхронного метода получения данных** в `pages/design-list/index.js`:

```javascript
async getData(query = "") {
    try {
        // fetch возвращает промис, ожидание реализации через await
        const url = query ? `/stocks?title=${query}` : '/stocks';
        const response = await fetch(url);

        // Преобразование ответа в JSON также требует await
        return await response.json();
    } catch (error) {
        console.error("Ошибка при запросе к серверу МГТУ:", error);
        return [];
    }
}
