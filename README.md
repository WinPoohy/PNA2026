## 🎯 Цель работы
Изучение основ экосистемы Node.js и работы с пакетным менеджером npm. Практическое освоение модульной архитектуры веб-приложений с использованием ES6 Modules (`import/export`), интеграция современного UI-фреймворка Bootstrap 5, а также реализация динамического рендеринга страниц на стороне клиента (Client-Side Rendering) с помощью JS-компонентов.

---

## 🛠️ Выполненные задачи & Особенности архитектуры

В рамках работы была заложена масштабируемая архитектура SPA (Single Page Application), кардинально отличающаяся от классической статической верстки:

| Этап / Технология | Описание технической реализации |
|---|---------------------|
| **Окружение Node.js & npm** | Инициализирован проект, сформирован дескриптор `package.json`. Управление зависимостями полностью переведено на пакетный менеджер. |
| **Интеграция Bootstrap 5** | Отказались от CDN в пользу локальной установки фреймворка (`npm i bootstrap`). Стили и JS-бандлы (включая Popper.js) подключаются напрямую из папки `node_modules`. |
| **Компонентный подход** | Логика интерфейса инкапсулирована внутри независимых JS-классов. Точка входа `main.js` отвечает за монтирование страницы в корневой узел `div#root`. |
| **Модульная система ES6** | Использованы нативные модули браузера (`type="module"`), что позволило изолировать контексты страниц и организовать чистые импорты компонентов. |
| **Динамический UI** | Верстка страниц вынесена из HTML в JS-методы `render()`, подготавливая базу для динамического изменения контента и фильтрации без перезагрузки вкладки. |
