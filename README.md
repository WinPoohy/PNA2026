## 1. Цель работы
Организация асинхронного взаимодействия клиентской части веб-приложения («Дизайн-услуги МГТУ») с внешним REST API с использованием технологии AJAX и объекта `XMLHttpRequest` (XHR). В ходе работы реализовано динамическое получение данных с бэкенда, обновление интерфейса без перезагрузки страниц (SPA-поведение), обработка CORS-ограничений на сервере Express.js, а также архитектурное разделение кодовой базы на сетевой слой и слой представления.

---

## 2. Структура проекта и конфигурация
В соответствии с требованиями лабораторной работы, сетевая логика вынесена в изолированный слой `modules`. Для запуска проекта используется связка **Vite** (для фронтенда) и **Express.js** (в качестве локального API-сервера).

### Файловая структура:
```bash
├── components/             # Переиспользуемые UI компоненты
├── pages/
│   └── design-list/        # Страница списка дизайн-услуг
├── modules/                # Сетевой слой приложения (AJAX)
│   ├── ajax.js             # Модуль инкапсуляции XMLHttpRequest
│   └── designUrls.js       # Конфигурация эндпоинтов REST API
├── index.html              # Главная страница портала
├── design.html             # Страница модуля дизайн-услуг
├── design-app.js           # Точка входа для клиентского приложения дизайна
├── package.json            # Манифест зависимостей (Vite, Express, Cors)
└── README.md               # Отчет по лабораторной работе
